## Publish with GitHub Pages

1. Create a public GitHub repository named exactly `haider45678.github.io`.
2. Upload all files and folders from this project to the repository root (do not upload the enclosing `haider-portfolio` folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish. Your site will be at `https://haider45678.github.io`.

Every push to the selected branch will publish an update.

## Optional custom domain

You can connect a domain later in **Settings → Pages → Custom domain**. Follow GitHub's current DNS instructions for your domain registrar and enable HTTPS after DNS verification.

## Add an Android app later

Update the “Products in progress” section in `index.html` and `apps/index.html` with the app name, short description, icon, screenshots and its Google Play listing URL. Add a separate app privacy policy page if its practices differ from this website.

## Local preview

Open `index.html` in a browser. No package installation is required.
